# `ascend_warmup_config`

> 启动预热配置：与权重加载重叠执行。

| 属性 | 值 |
|---|---|
| 类型 | `dict` |
| 默认值 | `{}` |
| 状态 | ✅ active（v0.30.0 新增） |

## 说明

在服务启动阶段安排预热计算（如算子预编译、内存池预热），并与权重加载流程重叠执行，缩短启动到可服务的总时间。

对大模型（权重加载耗时长）收益明显；具体子字段以对应版本的官方文档为准。

## 部署形态

> 混部 = PD 共置（colocated）或同机多实例共享 NPU；PD 分离 = P/D 节点经 KV 传输分离部署。「未见官方说明」≠ 不能开，仅表示官方文档未给出专门约束。

| 维度 | 结论 |
|---|---|
| 混部（colocated） | ◻️ 未见官方说明 |
| PD 分离 | ◻️ 未见官方说明 |

未见官方文档对本开关在混部（colocated）或 PD 分离部署下的专门说明；实践上可按全节点统一配置处理，欢迎补充实测结论。
